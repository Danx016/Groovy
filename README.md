# Groovy - Modern Music Streaming Player & Web Client

**Groovy** is a modern, high-performance music streaming application and web client with an elegant Apple Music-inspired interface. Stream your music library, discover recommendations, and sync lyrics smoothly on Android, iOS, Web, Windows, Linux, and macOS.

[![Groovy](https://img.shields.io/badge/Groovy-v1.0.14-fa243c?style=for-the-badge&logo=github)](https://github.com/Danx016)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)](LICENSE)

---

## ✨ Features

- 🎵 **Ultra-Fast Streaming** - Stream music instantly with zero latency
- 🎨 **Apple Music UI** - Sleek, modern dark aesthetic inspired by Apple Music
- 📱 **Cross-Platform** - Available on Android, Web, Windows, macOS, and Linux
- 🔍 **Instant Search** - Ultra-fast dual YouTube & Music search with intelligent caching
- 📚 **Personalized Feed** - Recommendations based on your favorite tracks and listening history
- 🎧 **Time-Synced Lyrics** - Smooth synchronized lyrics powered by LRCLIB
- 🚗 **Android Auto** - Full Android Auto integration for seamless car audio
- 📊 **Smart Queuing & Playlists** - Full queue management and local/cloud playlist support

## 🚀 Getting Started

### Flutter App

```bash
# Get dependencies
flutter pub get

# Run locally
flutter run

# Build Android Release APK
flutter build apk --release
```

### Web App (React)

```bash
cd react-website
npm install
npm run dev
```
